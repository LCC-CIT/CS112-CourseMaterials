Zombie River Crossing: Breadth-First Search

Humans and zombies must all cross from the left bank to the right bank. The boat needs at least one passenger to cross. If there are any humans on a bank, the zombies there must not outnumber them, or the humans get eaten.

By crossings layout: each node is a state, written as left bank ⛵│ right bank (the ⛵ shows which side the boat is on). Each column holds the states that take the same number of crossings to reach, shown by the number at the top. Breadth-first search finishes one column before starting the next, so the first time it reaches the goal it has used the fewest crossings.

State grid layout: the same states, placed by who has crossed. Each column is the number of humans on the right bank and each row is the number of zombies on the right bank, so the start is at the top left and the goal is at the bottom right.
