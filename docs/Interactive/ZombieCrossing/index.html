Zombie River Crossing: Breadth-First Search

Humans and zombies must all cross from the left bank to the right bank. The boat needs at least one passenger to cross. If there are any humans on a bank, the zombies there must not outnumber them, or the humans get eaten.

Each node in the graph is a state, written as left bank ⛵│ right bank (the ⛵ shows which side the boat is on). A state's level is the number of crossings it takes to reach it from the start. Breadth-first search finishes every state at one level before moving on to the next, so the first time it reaches the goal it has found a solution with the fewest crossings.

In the "By crossings" layout, the number above each column is how many crossings it takes to reach the states in it.
